# داشبورد مدیریت دارایی‌ها

داشبورد ثروت شخصی (SPA) با رابط فارسی و راست‌چین (RTL). نرخ زنده بازار طلا و ارز را از TGJU می‌گیرد، سبد دارایی را محاسبه می‌کند و همهٔ داده‌ها را فقط روی دستگاه کاربر در `localStorage` نگه می‌دارد.

نسخهٔ ۱.۰ — ذخیره‌سازی محلی، بدون سرور و بدون حساب کاربری.

## ویژگی‌های کلی

- چهار صفحه: پیشخوان، نرخ لحظه‌ای ارز و طلا، مدیریت دارایی‌ها، تنظیمات و پشتیبان‌گیری
- بنر چسبان نرخ زنده با فلش سبز/قرمز هنگام تغییر قیمت
- مخفی کردن موجودی‌ها در پیشخوان و دفتر دارایی (نرخ‌های هدر و صفحهٔ نرخ لحظه‌ای مخفی نمی‌شوند)
- تم روشن/تاریک با ذخیره در `localStorage`
- سایدبار راست‌چین و واکنش‌گرا (منوی همبرگری در موبایل)
- ارقام فارسی، جداکنندهٔ هزارگان، فونت Peyda
- **تخصیص هدف سبد:** تعیین درصد هدف هر کلاس، مقایسه با وضعیت فعلی و هشدار انحراف
- خروجی CSV / Excel / PDF، چاپ فارسی و پشتیبان JSON
- استقرار خودکار روی GitHub Pages از شاخهٔ `main`

## صفحات

### ۱. پیشخوان

نمای کلی سبد و روند ثروت.

**کارت‌های KPI**

| کارت | محاسبه |
|------|--------|
| جمع کل ثروت | جمع ارزش همهٔ کلاس‌ها (تومان) |
| معادل USDT کل ثروت | `portfolioTotal / usdtRate` |
| ارزش کل بخش طلا | مجموع کلاس با نام دقیق «طلا» |
| ارزش نقدینگی و USDT | کلاس «USDT» یا «دلار» + «درآمد ثابت» + «نقد / بانک» |

**هشدار ریسک تمرکز:** اگر سهم هر کلاس از ۶۰٪ کل ثروت بیشتر شود، هشدار زرد نمایش داده می‌شود:

> هشدار ریسک: بیش از ۶۰٪ از کل دارایی شما در کلاس [نام] متمرکز شده است. برای مدیریت ریسک، تنوع‌بخشی به سبد پیشنهاد می‌شود.

**نمودار تخصیص دارایی (دونات):** سهم هر کلاس (فعلی) با ارزش مثبت. راهنما با درصد فارسی. اگر دارایی نباشد: «دارایی‌ای ثبت نشده است.»

**مقایسه با تخصیص هدف** (وقتی اهداف در تنظیمات ذخیره شده باشند):

| ستون | معنی |
|------|------|
| هدف | درصد هدف تعریف‌شده برای کلاس |
| فعلی | درصد فعلی همان کلاس در سبد |
| انحراف | `فعلی − هدف` (مثبت = بیش‌وزن، منفی = کم‌وزن) |
| فاصله تا هدف | اختلاف ارزشی تا رسیدن به سهم هدف (تومان؛ مثبت = کمبود، منفی = مازاد) |

ستون‌های عددی جدول با جهت LTR نمایش داده می‌شوند. مبالغ و درصدها در حالت مخفی موجودی ماسک می‌شوند.

**هشدار انحراف از هدف:** اگر `|انحراف|` از ۵٪ (`TARGET_DRIFT_ALERT_THRESHOLD`) بیشتر شود، هشدار آبی با توضیح بیش‌وزن/کم‌وزن و تخمین فاصلهٔ تومانی نمایش داده می‌شود.

اگر تخصیص هدف تعریف نشده باشد، کارت راهنما با دکمهٔ رفتن به تنظیمات نشان داده می‌شود.

**تاریخچهٔ ثروت (`wealthHistory`):** در state و `localStorage` نگه‌داری می‌شود؛ آخرین نقطه وقتی جمع سبد بیش از ۰.۱٪ تغییر کند به‌روز می‌شود. نمودار خطی رشد در UI پیشخوان فعلاً نمایش داده نمی‌شود.

### ۲. نرخ لحظه‌ای ارز و طلا

مقایسهٔ قیمت بازار با ارزش ذاتی و دلار محاسباتی. دسکتاپ جدول است؛ موبایل کارت.

بالای جدول: `آخرین بروزرسانی: [ساعت] [روز هفته] [تاریخ شمسی]` از `lastSuccessfulFetch`.

| ستون | توضیح |
|------|--------|
| طلا و سکه | نام ردیف |
| آخرین قیمت | قیمت بازار از TGJU (تومان) |
| ارزش ذاتی | ارزش نظری بر اساس انس جهانی و نرخ دلار |
| حباب | درصد اختلاف آخرین قیمت با ارزش ذاتی؛ مثبت قرمز، منفی سبز، صفر خنثی |
| دلار محاسباتی | نرخ دلار ضمنی از قیمت بازار و انس جهانی |

**ردیف‌ها**

| ردیف | وزن / عیار | کلید قیمت |
|------|-------------|-----------|
| طلا گرم ۱۸ عیار | ۱ گرم، ۱۸ عیار | `gold18kPerGram` |
| سکه امامی | ۸.۱۳۳۹ گرم، ۲۱.۶ عیار | `coinSekee` |
| سکه بهار | ۸.۱۳۳۹ گرم، ۲۱.۶ عیار | `coinSekeb` |
| نیم سکه | ۴.۰۶۶۹ گرم، ۲۱.۶ عیار | `coinNim` |
| ربع سکه | ۲.۰۳۳۴ گرم، ۲۱.۶ عیار | `coinRob` |
| مظنه آب‌شده نقدی | ۴.۶۰۸ گرم با خلوص ۷۰۵/۱۰۰۰ | `mesghal` |
| طلا گرم ۲۴ عیار | ۱ گرم، ۲۴ عیار | `gold24kPerGram` |

**فرمول‌ها** (`src/utils/goldCalculations.js`)

- گرم طلای خالص در انس: `۳۱.۱۰۳۴۷۶۸`
- ارزش دلاری واحد: `وزن × (عیار / ۲۴) × (انس / گرم‌درانس)`
- مظنه: `۴.۶۰۸ × (۷۰۵ / ۱۰۰۰) × (انس / گرم‌درانس)`
- ارزش ذاتی (تومان): `round(ارزش دلاری × نرخ دلار)` — نرخ دلار از `usdRate` و در نبود آن از `usdtRate`
- حباب: `round(((قیمت − ذاتی) / ذاتی) × ۱۰۰۰) / ۱۰`
- دلار محاسباتی: `round(قیمت بازار / ارزش دلاری واحد)`

### ۳. مدیریت دارایی‌ها

جدول تو در تو برای کلاس‌ها و زیرآیتم‌ها. ارزش کل هر آیتم: `مقدار × ارزش واحد`. درصد هر ردیف نسبت به جمع کل سبد است.

**ستون‌ها:** نام، مقدار، واحد، ارزش واحد، ارزش کل، درصد از کل ثروت، عملیات.

کلیک روی ردیف کلاس (اگر زیرآیتم داشته باشد) آن را باز و بسته می‌کند. ردیف آخر جمع کل دارایی‌هاست.

**مرتب‌سازی کلاس‌ها** (زیرآیتم‌ها زیر والد می‌مانند)

| ستون | کلید | پیش‌فرض |
|------|------|---------|
| ارزش کل (تومان) | `total` | — |
| درصد از کل ثروت | `percent` | نزولی |

کلیک روی همان ستون جهت را عوض می‌کند؛ کلیک روی ستون دیگر همان ستون را نزولی می‌کند. تساوی عددی با نام فارسی شکسته می‌شود. فلش فقط روی ستون فعال است.

**کلاس جدید:** فیلد نام + «افزودن کلاس» (مثال: زمین، کریپتو).

**عملیات کلاس**

| دکمه | رفتار |
|------|--------|
| + | افزودن زیرآیتم با قیمت دستی |
| ماشین‌حساب (کلاس «طلا») | افزودن با منبع پیش‌فرض طلای ۱۸ عیار |
| ماشین‌حساب (کلاس «USDT» یا «دلار») | افزودن با منبع USDT |
| سطل زباله | حذف کلاس پس از تأیید |

**عملیات زیرآیتم:** ویرایش و حذف با تأیید.

**فرم افزودن/ویرایش**

- نام، مقدار، واحد (`سهم`، `عدد`، `گرم`، `دلار`، `واحد`، `دستگاه`؛ واحد سفارشی قبلی حفظ می‌شود)
- ارزش واحد دستی با جداکنندهٔ هزارگان (`react-number-format`)
- یا «محاسبه خودکار قیمت از نرخ زنده» با منبع قیمت و نمایش نرخ فعلی

**منابع قیمت خودکار**

| گروه | منبع | واحد پیش‌فرض | کلید نرخ |
|------|------|---------------|----------|
| طلا | طلای ۱۸ عیار (گرم) | گرم | `gold18kPerGram` |
| سکه | سکه تمام (امامی) | عدد | `coinSekee` |
| سکه | سکه تمام (بهار آزادی) | عدد | `coinSekeb` |
| سکه | سکه گرمی | عدد | `coinGerami` |
| سکه | نیم سکه | عدد | `coinNim` |
| سکه | ربع سکه | عدد | `coinRob` |
| ارز | نرخ USDT | USDT | `usdtRate` |
| ارز | نرخ دلار | دلار | `usdRate` |

کلاس‌ها و آیتم‌های قدیمی با نام «دلار» هنگام بارگذاری به «USDT» مهاجرت می‌شوند (`priceSource: usd` → `usdt`).

### ۴. تنظیمات و پشتیبان‌گیری

**تخصیص هدف سبد**

برای هر کلاس دارایی درصد هدف وارد می‌شود. ستون «درصد فعلی سبد» فقط برای راهنمایی است.

| کنترل | کاربرد |
|--------|--------|
| تقسیم برابر بین کلاس‌ها | اختصاص سهم مساوی به همهٔ کلاس‌ها (جمع ۱۰۰٪) |
| کپی از وضعیت فعلی سبد | پر کردن درصدها از درصدهای لحظه‌ای سبد |
| ذخیره اهداف | فقط وقتی فعال است که **همه** کلاس‌ها درصد داشته باشند و جمع = ۱۰۰٪ (تحمل ±۰.۰۵) |
| حذف اهداف | پاک کردن `targetAllocation` از state |

کلید ذخیره: `targetAllocation` — نگاشت `{ [classId]: درصد }`. با تغییر نام کلاس، اهداف به `id` وابسته‌اند نه به نام.

**ظاهر:** جابه‌جایی تم روشن/تاریک (`data-bs-theme` روی `documentElement`). پیش‌فرض تاریک است و ذخیره می‌شود.

**خروجی دفتر دارایی** (کلاس، نام، مقدار، واحد، ارزش واحد مؤثر، ارزش کل، درصد):

| دکمه | فرمت |
|------|------|
| CSV | UTF-8 با BOM |
| Excel | شیت «دارایی‌ها» |
| PDF | افقی، هدر انگلیسی (محدودیت فونت jsPDF) |
| چاپ / PDF فارسی | پنجرهٔ چاپ با Vazirmatn، تاریخ شمسی و ردیف جمع کل |

نام فایل‌ها: `{نام}_{تاریخ-ساعت-شمسی}.{پسوند}`.

**پشتیبان JSON**

- خروجی: کل state پایدار به‌جز `priceFlash`، `priceFetchStatus` و `sidebarOpen`
- ورودی: جایگزینی state؛ فایل نامعتبر پیام خطا می‌دهد

بازنویسی دستی نرخ در تنظیمات پیاده‌سازی نشده؛ نرخ از API یا آخرین مقدار ذخیره‌شده می‌آید.

## نرخ زنده (TGJU)

منبع: `GET https://call4.tgju.org/ajax.json`

فاصلهٔ به‌روزرسانی: هر ۶۰ دقیقه (`FETCH_INTERVAL_MS = 60_000 * 60`). اولین درخواست هنگام بارگذاری برنامه است.

| کلید state | فیلد API | تبدیل |
|------------|----------|--------|
| `goldOunceGlobal` | `ons.p` | دلار |
| `usdtRate` | `crypto-tether-irr.p` | ریال → تومان |
| `usdRate` | `price_dollar_rl.p` یا `price_dollar_dt.p` | ریال → تومان |
| `gold18kPerGram` | `geram18.p` | ریال → تومان |
| `gold18kBubble` | — | اختلاف گرم ۱۸ عیار بازار با ارزش نظری انس × USDT |
| `gold24kPerGram` | `geram24.p` | ریال → تومان |
| `mesghal` | `mesghal.p` | ریال → تومان |
| `coinSekee` | `sekee.p` | ریال → تومان |
| `coinSekeb` | `sekeb.p` | ریال → تومان |
| `coinGerami` | `gerami.p` | ریال → تومان |
| `coinNim` | `nim.p` | ریال → تومان |
| `coinRob` | `rob.p` | ریال → تومان |

حباب بنر برای گرم ۱۸ عیار:

`ارزش نظری = (انس / ۳۱.۱۰۳۴۷۶۸) × (۱۸ / ۲۴) × نرخ USDT`  
`حباب = ((قیمت بازار − ارزش نظری) / ارزش نظری) × ۱۰۰` با یک رقم اعشار.

اگر `ons`، `crypto-tether-irr` یا `geram18` نباشد، کل به‌روزرسانی رد می‌شود و آخرین نرخ ذخیره‌شده می‌ماند.

## ذخیره‌سازی

کلید: `wealth-dashboard-v1`

ذخیره می‌شود: تم، صفحهٔ جاری، قیمت‌ها، دارایی‌ها، تاریخچهٔ ثروت، `targetAllocation`، کلاس‌های باز، نمایش/مخفی موجودی، زمان آخرین دریافت موفق.

ذخیره نمی‌شود: `priceFetchStatus`، `priceFlash` (پس از بارگذاری دوباره وضعیت `cached` است).

## دادهٔ اولیه (اولین اجرا)

| کلاس | آیتم | مقدار | قیمت |
|------|------|--------|------|
| خودرو | پژو ۲۰۷ MC | ۱ دستگاه | ۸۵۰٬۰۰۰٬۰۰۰ تومان (دستی) |
| طلا | طلای ۱۸ عیار | ۵۰ گرم | خودکار از گرم ۱۸ عیار |
| USDT | USDT | ۳۰۰۰ USDT | خودکار از نرخ USDT |
| سهام | فولاد مبارکه | ۲۰٬۰۰۰ سهم | ۲٬۰۰۰ تومان |
| درآمد ثابت | صندوق لوتوس | ۱٬۰۰۰ واحد | ۱۰۰٬۰۰۰ تومان |

تاریخچهٔ نمونه: آبان ۱۴۰۳ تا فروردین ۱۴۰۴.

قیمت‌های پیش‌فرض (`DEFAULT_PRICES`) فقط تا اولین دریافت موفق API استفاده می‌شوند.

## مدل داده

```text
assetClass = { id, name, items[] }
item       = { id, name, quantity, unit, unitPrice, autoPrice, priceSource }
state      = { ..., targetAllocation: { [classId]: number /* percent 0–100 */ } }
```

`priceSource` وقتی `autoPrice === true` یکی از این‌هاست: `gold18k`، `sekee`، `sekeb`، `gerami`، `nim`، `rob`، `usdt`، `usd`.

اکشن `SET_TARGET_ALLOCATION` کل نقشهٔ اهداف را جایگزین می‌کند. `portfolioSummary.targetDrift` شامل `rows`، `alerts` و `isActive` است (محاسبه در `src/utils/targetAllocation.js`).

| `npm run build` | ساخت production (خروجی `dist/`) |
| `npm run preview` | پیش‌نمایش build |
| `npm run lint` | ESLint |

پوش به `main` ورک‌فلو `.github/workflows/jekyll-gh-pages.yml` را اجرا می‌کند: `npm ci` → `npm run build` → انتشار `dist/` روی GitHub Pages.
